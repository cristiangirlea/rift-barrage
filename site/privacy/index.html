Privacy

Applies to the Rift Barrage preview builds (versions 0.1 and 0.2) for Android and Windows downloaded from this site or its GitHub releases. Last updated 2 October 2026.

What the game collects

Nothing. The preview has no account, no sign-in, no advertising, no in-app purchases, no analytics and no crash reporting. It does not send your data anywhere.

What stays on your device

Your progress and settings are saved in a file on your own device so you can continue later. Uninstalling the game (Android) or deleting its data folder (Windows) removes it. Settings → Reset profile starts over and keeps the previous file on the device in case you change your mind.

Android permissions

The Android package lists the standard internet permission because the game engine includes it by default. The preview itself makes no network requests.

Future versions

If a later version adds online features, ads or purchases, this page will be updated before that version is offered, and it will explain what is collected and why.

Contact

Questions or requests: open an issue at github.com/cristiangirlea/rift-barrage.
