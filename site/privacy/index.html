Privacy

Applies to the Rift Barrage preview builds (versions 0.1 to 0.4) for Android and Windows downloaded from this site or its GitHub releases. Last updated 20 November 2026.

What the game collects

The preview has no game account, sign-in, advertising, in-app purchases, or developer-configured analytics or crash reporting. Gameplay progress and settings are stored locally on your device.

What stays on your device

Your progress and settings are saved in a file on your own device so you can continue later. Uninstalling the game (Android) or deleting its data folder (Windows) removes it. Settings → Reset profile starts over and keeps the previous file on the device in case you change your mind.

Version 0.3 converts earlier progression into the research system and retains an archive of the original save on the device.

Android permissions

The Android package includes internet permission. The game uses the Unity engine; Unity describes potential device and network data processing in its game player privacy policy. We are verifying the exact runtime behavior of the preview and will update this page if that review identifies additional processing.

Future versions

If a later version adds online features, ads or purchases, this page will be updated before that version is offered, and it will explain what is collected and why.
